✅ 保存成功！还差最后一步（Steam 没开 API，必须手动）

  1. 打开 Steam 库 → Dota 2 → 右键 → 属性 → 启动选项
  2. 填入：-gamestateintegration -condebug
  3. 关 Steam 再开（让启动选项生效）
  4. 关闭这个窗口；右上角托盘图标会变橙色就 OK 了
