Dota Coach

你的私人 Dota 2 教练

实时层在游戏中给你中文语音决策提醒（GSI + Console log，全部 Valve 官方接口）； 复盘层每周用 Claude 自动挖掘"赢局 vs 输局"的盲区，生成 3 条训练任务。

Windows 一键安装

1

PowerShell 跑这一行

irm https://dota.bowie.top/install.ps1 | iex

脚本会自动：装 Python+uv → clone 仓库 → 装依赖 → 交互式问你 Steam ID 和 Anthropic API key → 部署 GSI 配置。

需要的两个东西可以提前准备好：

  • • Steam 32-bit ID：去 opendota.com 搜你的名字，URL 里 /players/12345 那串
  • • Anthropic API key：console.anthropic.com 创建
2

改 Dota 启动选项（手动唯一一步）

Steam → 库 → Dota 2 → 右键 → 属性 → 启动选项，填：

-gamestateintegration -condebug

为啥要手动？Valve 没开 API 让外部程序改这个，硬改 Steam 配置文件容易翻车。

3

启动实时层

cd $HOME\dota-coach
uv run dotacoach run

建议加到任务计划程序里设为开机启动。

🍎

macOS 一键安装

1

终端跑这一行

curl -fsSL https://dota.bowie.top/install.sh | bash

同 Windows 流程，自动装 uv + 依赖 + 交互配置 + GSI。

2

改 Dota 启动选项

Steam → 库 → Dota 2 → 右键 → 属性 → 启动选项：

-gamestateintegration -condebug

使用

实时层（常驻）

uv run dotacoach run

开 Dota 自动接管。耳机里听播报。按 F8 切换全局静音。

手动复盘

uv run dotacoach weekly

默认拉过去 7 天的对局。报告写到 data/reports/，并推送到飞书。

自动周报告

实时层进程内嵌 APScheduler，每周日凌晨 03:00 自动跑复盘并推送，无需额外配置。

想长时间保持运行：Windows 用任务计划程序，macOS 用 launchctl。

常见问题

会不会封号？ ▼

不会。本工具只用 Valve 官方公开的 GSI 接口和 console.log 输出，不读取游戏内存、不修改游戏文件、不模拟操作。 Valve 自己说明 GSI 就是给第三方工具用的。Dota Plus 内置的物品建议、肉山计时器，机制上是一样的。

能看到敌方位置/CD 吗？ ▼

不能"开图"。敌方信息只有在你视野内才会进 console.log。例如你看到敌方莱恩开了大，工具会从那一刻开始倒计时；你没看到的就算不出来。 这是合规边界，也是设计上的选择。

每周一次 Claude 调用要花多少钱？ ▼

启用了 Prompt Caching，预估月成本 < $1。一次复盘的输入是统计差异 + 几个典型局摘要，输出 JSON 报告，token 量很小。

语音太吵怎么办？ ▼

默认只启用 ~10 条核心规则，每条都有冷却（默认 30 秒），团战中自动 mute 非关键提醒。还嫌吵就按 F8 全局 mute，或编辑 config/rules.yaml 把不喜欢的规则 enabled: false。

没听到播报？ ▼

排查顺序：

  1. 启动选项是不是加了 -gamestateintegration -condebug？
  2. dotacoach run 控制台有没有看到 GSI 推送日志？
  3. 音频输出设备是不是耳机/扬声器？edge-tts 走系统默认输出
  4. 试试 uv run python -c "import asyncio; from dotacoach.realtime.voice_backends import make_backend; asyncio.run(make_backend('edge').speak('测试'))"
我能改提醒规则吗？ ▼

能，全在 config/rules.yaml。每条规则有 when（Python 表达式）和 say（播报文本）。改完重启 dotacoach run 即可生效。

架构一览

打比赛
  ↓
GSI + Console log → 规则引擎 → TTS 语音 → 你的决策
  ↓ (赛后)
OpenDota API → SQLite
  ↓ (每周日凌晨)
模式挖掘（赢局 vs 输局差异）→ Claude API → 周报告
  ↓
生成下周训练任务（3 条）
  ↓
下周打比赛时实时层会盯着这些任务的指标
  ↓ (一周后)
下周报告里验证：上周任务有没有改善？→ 新一轮
